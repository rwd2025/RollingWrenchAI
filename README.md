# Rolling Wrench AI — Tactical React Native Home Screen

This ZIP turns the dashboard mockup into a polished React Native / Expo home screen.

## Fix included
Your pasted code had this bug at the bottom:

```js
StyleSheet.style({
```

It must be:

```js
StyleSheet.create({
```

This build already fixes that and adds a more polished responsive layout.

## Run it

```bash
npm install
npx expo start
```

Then open it in Expo Go or your simulator.

## Files
- `App.js` — full home screen
- `package.json` — Expo dependencies
- `README.md` — setup notes
