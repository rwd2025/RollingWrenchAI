# Rolling Wrench AI — GitHub Pages Tactical Build

This is the GitHub Pages version.

Upload these files to the root of your repo:

- `index.html`
- `style.css`
- `app.js`
- `README.md`

Your live URL will load `index.html`.

## Important
Delete or replace the old `index.html`, old CSS, and old JS first.  
GitHub Pages only shows what is in the repo root or selected Pages folder.

## After upload
Wait 2–10 minutes, then hard refresh Safari.
